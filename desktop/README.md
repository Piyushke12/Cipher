## Cipher Integration

This desktop application integrates with the **Cipher** autonomous security assessment agent. Key features:

- Terminal UI for interacting with Cipher
- Assessment targeting and scope management
- Real-time token usage monitoring
- findings and vault key display
- Compact summarization of older turns

## Getting Started

```bash
npm install
cipher tauri dev
```

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build the application
- `cipher tauri build` - Build Tauri app
